# 🎪 音乐节摊位动线工具

观众选择 **起点 → 舞台 → 餐饮摊 → 洗手间 → 出口**，系统综合**距离、人流拥挤度、封控路段**推荐最优动线；
前端展示分程路线卡片与简化场地图；后台可实时更新节点开放/路段状态，观众端刷新后路线自动重新计算。

## 启动

```bash
cd festival-router
npm install        # 仅依赖 express
node server.js
```

- 观众端：http://localhost:3000
- 后台管理：http://localhost:3000/admin.html

## 功能

### 观众端
- SVG 简化场地图：舞台🎤 / 餐饮🍢 / 洗手间🚻 / 出口🚪，路段按拥挤度四色显示，封控路段灰虚线 + ⛔
- 五段式动线规划：起点 → 舞台 → 餐饮 → 洗手间 → 出口，推荐路线在地图上以彩色动画高亮
- 路线卡片：途经节点、距离、预计分钟、拥挤度徽章、「已智能避堵绕行」标记
- 每 12 秒自动轮询后台状态；状态变更时自动重算并提示，也可手动「🔄 刷新路线」
- 目标关闭/全程封控时给出不可达提示，后续行程级联标记

### 后台管理
- 节点开关（如摊位临时关闭、洗手间维护）
- 路段封控/解封、拥挤度 4 档调整（畅通 / 一般 / 拥挤 / 严重拥堵）
- 所有变更持久化到 `data/venue-state.json`，服务重启不丢失；可一键恢复初始状态

## 规划算法（venue.js）

- 图模型：18 个节点（含 7 个路口）、26 条无向路段
- **Dijkstra**，权重 = 距离 × 拥挤惩罚系数（1.0 / 1.4 / 2.2 / 3.5）
- 封控路段、关闭节点在建图时直接剔除 → 自动绕行
- 步行耗时按拥挤度折算速度（1.25 m/s × 1.0 / 0.8 / 0.55 / 0.35）
- 与"纯最短距离路径"对比，若不一致则标记为智能避堵绕行

## API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/venue | 节点/路段最新状态 |
| POST | /api/plan | 入参 `{start, stage, food, restroom, exit}`，返回各段路线 |
| POST | /api/admin/node/:id | `{open: boolean}` 更新节点开放状态 |
| POST | /api/admin/edge/:id | `{closed?, congestion? 0-3}` 更新路段 |
| POST | /api/admin/reset | 恢复初始演示状态 |
